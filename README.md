# Mock-Anheuser-Busch-Sales-Analysis

## Description
--------------
Built an end-to-end data analysis project simulating Anheuser-Busch product sales across four U.S regions. Started with a small seed dataset and used Python (Pandas, NumPy) in Jupyter Notebook to generate over 1,500 semi-realistic sales records, applying a rank-weighted randomization method so unit sales aligned with real product popularity. Loaded the dataset into a MySQL database using mysql-connector-python, writing the table creation and insert script, plus SQL queries to validate the data. Exported results to Excel to build pivot tables and charts, uncovering insights like Corona Extra outselling Bud Light in revenue despite lower unit volume due to price-point differnces.
